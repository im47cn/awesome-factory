# ddl-guard eval 008 — 真实缺陷 DDL（混合型拦截）

check: ddl_check.py

## 说明

本 case 为**混合型**评估样本：input/ 为真实生产缺陷 DDL（含必含字段缺失、
普通索引命名、泛化字段名、注释格式、禁用类型、缩写未规范化等问题），
作为拦截型与放行型之间的中间难度。用于打分器 recall 侧验证——
「该拦的拦到」。

## 预期检查输出

- 脚本自动检出：必含字段缺失、必含字段注释不一致、逻辑删除字段缺失、普通索引命名、索引名未包含全部字段、索引缩写未规范化、泛化字段名、注释格式、禁用类型、缩写未规范化
- 人工补充：字段与注释语义对应、表注释缺失需人工确认（脚本部分覆盖）
- 人工补充规则：字段与注释对应|注释含义对应|语义对应|词汇对应
